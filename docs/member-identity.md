# 内容台成员登录与修改记录

内容台使用已登记的姓名和学号登录。登录状态由服务器会话保存，停用成员后会话失效。网站管理员可以维护成员姓名、学号、部门、职务、账号状态与权限，并查看修改记录。主网站管理员账号受服务器保护，不能停用或降为普通成员。

材料提交与审核的操作人来自当前登录账号，界面不再允许手工填写操作人姓名。网站内容、文件上传、材料流程等修改由服务器保存操作账号、时间、操作对象和修改内容；登录前的旧操作无法追溯到具体账号。

管理员进入内容台后，可在侧栏选择「成员名单」和「修改记录」。名单支持搜索、新增、编辑、停用和重新启用。记录分页展示，点击「查看」可查看修改前后内容。

姓名、学号并非秘密，因此该方式只能识别使用了哪个账号，不能充分验证本人身份。不要将账号记录视为不可冒用的身份证明。
