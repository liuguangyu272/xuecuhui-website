# 资料阅读器

资料库的 Markdown、PDF 卡片进入 `reader.html?id=资料ID`。阅读页从 `/api/data` 查找原有资料记录，读取记录中的文件地址；现有附件无需重新上传。其他历史附件继续使用原有文件入口。本次内容台的资料文件选择器仅提供 `.md` 和 `.pdf`。

## Markdown

支持标题及目录、列表、引用、表格、链接、图片、代码高亮和复制。Markdown 不执行 HTML 或脚本，程序代码只显示、不执行。相对图片和附件地址以原始 Markdown 文件所在目录为基准。

目录复用已排版的标题，保留数学公式，不从 MathML 注释中提取 LaTeX 源码，收录一至四级标题。桌面目录常驻侧边；900px 及以下显示左侧触碰展开的目录抽屉，选择章节自动关闭，支持遮罩、关闭按钮与 Escape，并为目标标题预留顶部空间。正文缩小嵌套列表缩进，长公式、表格、代码块可在自身区域横向滚动；PDF 手机工具栏分两行显示，按钮至少 44px 高。手机首页提供公告、活动、资料、小帮手及加入我们快捷入口，门户页面的导航菜单保留完整板块入口。

数学公式使用 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`；也支持 `math` / `latex` 代码块。KaTeX 只支持其文档列出的 LaTeX 数学指令，未提供完整 `.tex` 文档编译或任意宏包运行。化学方程式由 mhchem 提供，例如：

```latex
\ce{CH3COOH <=> H+ + CH3COO-}
```

用 `smiles` 代码块输入分子结构，例如 `CC(=O)O`。阅读器通过 SmilesDrawer 在浏览器生成 SVG，不需要调用服务器的药化生成流程。复杂反应机理可使用已有图片，当前不提供化学结构手绘编辑器。

内容台「资料分类」支持直接编写新 Markdown、预览、保存；已有 Markdown 使用「编辑正文」。保存时上传新版本附件并更新原资料记录，保留资料 ID 和单独水印设置；原附件不覆盖。在线编辑/渲染限制为 5MB，较大文件保留下载入口。保存失败保留正文，重试不会新增重复资料记录。

## PDF

自托管 PDF.js 模块、worker、CMap、字体及解码资源。支持按页阅读、跳页、放大缩小、适宽和文本选择。按需绘制当前页，限制单页画布像素，避免长 PDF 一次性占满内存。扫描版的文字选择依赖文件本身的文本层，当前不执行 OCR。加密 PDF 会提示输入密码；损坏、丢失或加载失败的文件显示错误并保留原文件入口。外部文件需允许浏览器跨域读取，否则可从原文件入口打开。

## 水印

默认开启，文字为「中国药科大学药学院 · 学促会」，最长 80 字。`library.watermark` 保存全局 `{enabled, text}`；每份 `doc.watermark` 可覆盖其中的字段，缺失字段继承全局设置，旧资料自动适用默认值。

水印在阅读时作为不可点击的重复 SVG 背景叠加：Markdown 铺满正文，PDF 铺满当前页，翻页和缩放后保留。水印文字通过 SVG textContent 编码，避免被当成标签。它不修改源文件，下载原文件也不会增加水印；这不是防复制机制。当前未提供带水印 PDF 下载或 Office 预览。

## 构建与检查

前端保持原生多页面结构。依赖固定在 `package-lock.json`，部署直接使用已提交的 `web/assets/vendor/`，线上无需 npm 安装或临时访问 CDN。

维护渲染依赖时执行 `npm ci`，再执行 `npm run build:reader`；同时提交依赖清单、源码及生成的 vendor 文件。第三方许可保留在 `web/assets/vendor/licenses/`。

`npm run test:reader` 使用 Playwright，在隔离的本地服务中检查阅读、移动端布局、水印与内容台保存。默认使用本机 Microsoft Edge；可用 `READER_BROWSER=chromium` 选择已安装的 Playwright Chromium。`READER_INSECURE=1` 验证普通 HTTP 非安全上下文，`READER_QA_DIR` 指定截图目录。测试仅修改临时 API 数据，不操作线上内容。
