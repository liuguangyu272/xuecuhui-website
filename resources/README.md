# 学习小站 · 当前公开资料

这里保存网站当前公开资料。CMS 发布后通过服务器持久化队列和 GitHub API 自动记录版本，口令、密钥、服务器配置和面板数据库不进入仓库。

| 目录 / 文件 | 内容 |
| --- | --- |
| [高数十月复习资料](assets/docs/477e841f37722e16.md) | 函数、数列极限、函数极限和极限计算 |
| `assets/posters/` | 当前活动海报 |
| `content.json` | 网站已公开的公告、活动、部门、资料目录等内容 |
| `question-banks/yaofen/` | 药物分析题库（4 个数据文件） |
| `question-banks/yaoji/` | 药剂学题库（5 个数据文件） |
| `question-banks/yaohua/` | 网站当前药化分子数据 |
| `editor/content_data.js` | 内容台当前题目、卡片数据导出 |
| `editor/yaohua/` | 药化编辑源数据及当前 63 张卡片引用的图片 |
| `manifest.json` | 文件清单、字节数与 SHA-256 校验值 |

内容台后续发布会自动同步本目录，新增、修改及移除的附件引用会更新 GitHub 对应文件。修改本目录不会反向覆盖线上数据；同文件并发修改时暂停同步供管理员处理。最新自动同步清单为 `cms-manifest.json`，原 `manifest.json` 仅保留首次导出记录。详情见 [CMS 自动同步](../docs/cms-sync.md)。

只收录当前引用的图片，未加入原始裁剪图、旧图目录、历史压缩包或旧版本快照。源码中的口令占位符由服务器本地配置填入，真实口令不在本目录。
